# Dataset instructions

This project uses the public Kaggle Bank Marketing dataset.

## Download

1. Create a Kaggle account and accept the dataset terms.
2. Download the dataset from:
   https://www.kaggle.com/datasets/volodymyrgavrysh/bank-marketing-campaigns-dataset
3. Place the downloaded CSV file in this folder:
   `data/`
4. Use a file name such as:
   `bank_marketing.csv`

## Important notes

- Do not commit the raw dataset to GitHub.
- The repository intentionally ignores large dataset files via `.gitignore`.
- The project code expects the dataset to be present locally before running the notebooks.
- Keep a dataset citation in the final report and README.

## Suggested local folder

```text
data/
  bank_marketing.csv
```
